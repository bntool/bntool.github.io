快速开始

四步开始使用

先添加账号，再选择插件和任务范围。

  1. 01

    下载并运行安装程序

    下载 Windows 安装包并完成安装，运行时和插件已随包提供。

  2. 02

    添加账号

    在“账号管理”中添加统一身份认证账号；需要校园网认证时填写对应的校园网密码。

  3. 03

    选择插件与任务

    打开目标插件，选择账号和任务范围。插件更新随主程序版本发布。

  4. 04

    启动任务并查看进度

    启动插件后，可在运行页查看任务流程、分线程进度和预计剩余时间。

常见问题

安装与运行说明

Windows 显示“未知发布者”怎么办？

当前测试版安装包尚未进行代码签名。确认安装包来自本页面或官方 Releases 后，可选择“更多信息”并继续安装。

需要预先安装 Python 或 EdgeDriver 吗？

不需要。安装包已包含 Python 运行时；EdgeDriver 会根据本机 Edge 版本自动获取。

首次安装后还需要下载插件吗？

不需要。安装包附带发布时的最新版插件，并会校验版本和文件完整性；后续随主程序更新。

配置和缓存保存在哪里？

统一保存在 %LOCALAPPDATA%\CrowKit。卸载应用时默认保留这些数据。

是否适合直接用于关键任务？

当前为 0.2.0 正式版，建议先使用少量任务验证配置和运行结果。
